Proyecto: Sprint 7 - Introducción a las pruebas automatizadas

Descripción: Pruebas para la creación de un kit asociado a un usuario enfocadas en las validaciones del campo "name" en el cuerpo de la solicitud.

⦁ La documentación se encuentra almacenada en Apidocs

⦁ Necesitas tener instalados los paquetes pytest y request para ejecutar las pruebas.

⦁ Para realizar las pruebas, se necesita primero crear un usuario y obtener un token válido

⦁ Ejecuta todas las pruebas con el comando pytest.

⦁ Las rutas de los endpoinds necesarios están en el archivo configuration.py
⦁ Todas las solicitudes necesarias para las pruebas se almacenan en el archivo sender_stand_request.py

⦁ El archivo data.py contiene los encabezados y parámetros necesarios en los cuerpos de las solicitudes utilizadas
